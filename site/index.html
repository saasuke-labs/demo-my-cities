About This Project

My Cities is a joyful experiment to showcase Gengo (static site generator), GSX (data sync), and Kotomi (comments & reactions). It's your playful guide to planning the next great trip — and a testbed for modern web tools.

Tech Behind the Magic

  • Gengo: Fast, flexible, and built for static site generation
  • GSX: Syncs data from APIs and other sources seamlessly
  • Kotomi: Makes interaction possible with comments and reactions
